# Sistema de Gerenciamento de Psicólogos e Pacientes

## Objetivo
O objetivo do projeto é desenvolver a modelagem de uma plataforma que centralize o gerenciamento de psicólogos, pacientes, usuários, agendamentos, consultas/atendimento e estatísticas, permitindo organizar essas informações em um único sistema e definir claramente como seus componentes irão se relacionar.

## Escopo
A plataforma terá como finalidade centralizar o gerenciamento administrativo e profissional de uma organização composta por psicólogos de diferentes áreas de atuação.

## Funcionalidades principais
- Gerenciamento de usuários, perfis e permissões
- Cadastro e gerenciamento de psicólogos e clientes/pacientes
- Vínculo entre profissionais e pacientes
- Gerenciamento de disponibilidade e agendamentos
- Confirmação e cancelamento de atendimentos
- Registro conceitual de atendimentos
- Auditoria das operações realizadas
